# Physiologically Constrained Decoding of Surface Electromyography for Subject-Independent Upper Limb Fatigue State Classification

Surface electromyography is the primary non-invasive tool for monitoring muscle fatigue. Standard classifiers label each signal window independently and ignore a basic physiological fact: within a single bout of exertion, fatigue accumulates monotonically and does not spontaneously reverse. This study introduces a decoding pipeline that enforces this constraint. A monotonic Viterbi decoder finds the globally optimal non-decreasing label sequence over a trial in linear time, and a progress-aware sigmoid prior, estimated from training data, encodes the expected pacing of fatigue and is blended with classifier posteriors before decoding. The pipeline was evaluated with strict leave-one-subject-out cross-validation on a public dataset of 13 healthy adults performing 12 dynamic upper-limb movements under a three-level fatigue scale, using a 128-dimensional feature set from four-channel surface electromyography. XGBoost achieved a macro-averaged F1 of 0.719, compared with 0.703 for raw argmax decoding; the gain was consistent across all five classifiers and statistically significant after Bonferroni correction. The three trial-progress features ranked above all 125 signal-derived features. Exploiting the irreversibility of fatigue progression thus improves subject-independent classification at negligible computational cost.
